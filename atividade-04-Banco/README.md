# Exercício Prático

Cenário: Análise de Risco em Carteira de Crédito.

Um banco tem 500 clientes com empréstimos ativos. Use Python + SciPy para analisar o risco da carteira e apoiar decisões de concessão de crédito.

## Colunas do Dataset

| Parâmetro | Valor |
| --- | --- |
| Total de clientes | 500 |
| Inadimplentes | 60 (12%) |
| Renda alta + adimplente | 180 |
| Renda alta (total) | 220 |
| Solicitações/hora (λ) | 3 |
| Score médio (μ) | 650 |
| Desvio padrão score (σ) | 80 |
| P(fraude) | 0,5% |
